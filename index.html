Tentang Saya

Perkenalkan, nama saya Muhamad Sopiyan Ansori. Saya memiliki latar belakang pendidikan di bidang Rekayasa Perangkat Lunak dan saat ini sedang menempuh pendidikan S1 Teknik Informatika. Dalam aktivitas profesional, saya banyak terlibat dalam bidang analisis data dan performance reporting, khususnya pada lingkungan Customer Care Group di industri perbankan. Pekerjaan saya berkaitan dengan pengolahan, analisis, dan monitoring data operasional layanan nasabah melalui berbagai kanal, seperti Contact Center, Live Chat, Media Sosial, Email, dan Telesales. Saya juga bertanggung jawab dalam membantu menyusun laporan kinerja, memantau pencapaian Key Performance Indicator (KPI), menganalisis tren interaksi dan pengaduan nasabah, serta mengidentifikasi faktor-faktor yang memengaruhi performa layanan. Dalam mendukung pekerjaan tersebut, saya menggunakan Microsoft Excel, Power BI, dan Python untuk pengolahan data, analisis, serta visualisasi informasi menjadi dashboard dan laporan yang dapat digunakan sebagai bahan evaluasi maupun pengambilan keputusan manajemen. Bagi saya, pekerjaan ini bukan hanya tentang mengolah angka, tetapi juga bagaimana menerjemahkan data menjadi informasi dan insight yang dapat membantu perusahaan meningkatkan kualitas layanan dan efektivitas operasional.
